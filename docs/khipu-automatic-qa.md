# Khipu automatic reconciliation — isolated QA
The external $2,990 DemoBank payment was verified by authenticated GET, with one payment binding. This change introduces Khipu-only inbox configuration and a targeted, retryable notification coordinator. It never creates payments, trusts callback status, or writes the real contract fee. A separate webhook ingress, actual development merchant signing secret, and HTTPS callback accessible to Khipu are still required; do not disable protection on matchter-beta or reuse the API key as the signature secret without provider confirmation. The existing paid checkout did not specify notify_url; a new explicitly isolated test obligation is required for a genuine provider callback. No production route or UI changes.
